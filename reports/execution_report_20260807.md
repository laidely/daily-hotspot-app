## 六、第五步：RAG 系统落地方案

针对 P2（信息过载）、P3（决策不可追溯）、P5（选型成本高）设计 RAG 系统：

### 全链路设计
```
文档解析 → 语义切块 → 向量化 → 混合检索 → 重排序 → 带引用生成
```

### 技术选型

| 层级 | 选型 |
|------|------|
| 文档解析 | Trafilatura + PyMuPDF |
| 文本切块 | LangChain RecursiveCharacterTextSplitter |
| 向量化 | BAAI/bge-m3 (1024 维，中英多语言) |
| 向量存储 | Qdrant (Docker，稠密+稀疏) |
| 混合检索 | 向量 + BM25 + RRF 融合 |
| 重排序 | BAAI/bge-reranker-v2-m3 (Cross-Encoder) |
| 生成 | DeepSeek-V3 (1% 成本优势) |
| 服务 | FastAPI + Uvicorn |

### 核心亮点
- 带来源标注的答案生成，解决 Agent 决策不可追溯
- 定时索引管道保障信息时效性
- 轻量化部署，单台 4C8G + GPU 可起步
- 提供完整关键代码（解析/切块/向量化/检索/重排/生成）
