# 每日热点智能聚合器 DailyHotspot

> 一个面向移动端的纯前端 H5 应用，聚焦"AI 时代信息过载"痛点，提供热点智能聚合、AI 深度摘要、多视角解读、个性化推荐与效率可视化。无需后端，浏览器直接打开即可运行。

- 版本：v1.0.0
- 数据基准日：2026-08-02
- 技术栈：原生 HTML + CSS + JavaScript（零依赖、零构建）

---

## 一、背景与解决的痛点

基于 2026 年 8 月 2 日热点分析，本应用针对性解决三大痛点：

| 痛点 | 现状 | DailyHotspot 的解法 |
| --- | --- | --- |
| 信息过载与智能聚合缺失 | 每日热点爆炸增长，缺乏智能过滤 | 分类筛选 + 兴趣推荐 + AI 摘要，主动降噪 |
| 移动端 AI 办公体验割裂 | 缺少原生移动交互 | 移动优先 H5、底部 Tab、下拉刷新、原生触感 |
| AI 价值度量缺失 | 缺乏效率可视化 | 效率仪表盘：阅读量/摘要数/分类偏好/效率得分 |

## 三、功能清单

1. **热点信息流**：卡片式展示，支持分类筛选（AI应用 / 办公自动化 / 效率工具 / 开发者趋势）。
2. **AI 智能摘要**：点击热点或"AI摘要"按钮，展开 AI 生成的深度解读（模拟数据）。
3. **多视角解读**：模拟马斯克 / 雷军 / 张一鸣 / 王兴 四位名人的观点卡片，底部弹窗呈现。
4. **个性化推荐**：基于用户兴趣标签对热点打分排序，兴趣可编辑并持久化。
5. **效率仪表盘**：关键指标卡片 + 近 7 天阅读柱状图 + 分类偏好环形图 + 效率得分进度条。
6. **搜索功能**：关键词搜索（标题/摘要/标签），防抖 300ms，大小写不敏感。
7. **底部 Tab 导航**：首页 / 分类 / 推荐 / 我的。
8. **下拉刷新与上拉加载**：首页原生下拉刷新、分页上拉加载更多。
9. **深浅色主题**：CSS 变量驱动，跟随系统并支持手动切换、持久化。

## 四、技术架构

### 4.1 目录结构

```
app/
├── index.html          # 主页面（应用骨架 + 四视图 + Tab 导航 + 弹窗）
├── test.html           # 独立测试页（加载后自动运行测试套件）
├── styles/
│   └── main.css        # 主样式（CSS 变量主题、移动端响应式、组件样式）
├── js/
│   ├── data.js         # 模拟数据层（DataAPI：分页/筛选/搜索/推荐/详情）
│   ├── app.js          # 核心逻辑（渲染/交互/虚拟列表/懒加载/仪表盘）
│   └── test.js         # 测试用例（34 项，覆盖数据/工具/虚拟列表/应用逻辑）
└── README.md           # 项目说明（本文件）
```

### 4.2 架构分层

```
┌─────────────────────────────────────────────┐
│  视图层 (index.html + main.css)              │
│  ─ 顶部头部 / 四视图容器 / 底部 Tab / 弹窗     │
├─────────────────────────────────────────────┤
│  逻辑层 (app.js)                             │
│  ─ utils 工具 / state 状态 / 各 View 模块     │
│  ─ VirtualList 虚拟列表 / LazyLoader 懒加载   │
│  ─ pullRefresh / search / tabNav / theme     │
├─────────────────────────────────────────────┤
│  数据层 (data.js)                            │
│  ─ HOT_NEWS / CELEBRITIES / USER_PROFILE     │
│  ─ DataAPI（模拟后端：分页/筛选/搜索/推荐）     │
└─────────────────────────────────────────────┘
```

- **零依赖**：不引入任何框架与 npm 包，原生 JS 实现。
- **模块化**：`utils` / `state` / `homeView` / `categoryView` / `recommendView` / `mineView` / `perspectivesModal` / `pullRefresh` / `search` / `tabNav` / `theme` 等模块职责单一。
- **数据契约**：`DataAPI` 对外提供不可变数据（深拷贝），模拟后端接口契约。

### 4.3 性能优化（移动端架构师负责）

| 优化项 | 实现方式 | 位置 |
| --- | --- | --- |
| 虚拟列表 | 仅渲染可视区+缓冲区，`translateY` 定位，动态测量高度缓存，二分查找可视区间 | `app.js` `VirtualList` 类 |
| 图片懒加载 | `IntersectionObserver` + `data-src`，`rootMargin` 预加载 200px | `app.js` `lazyLoader` |
| 防抖 | 搜索输入 300ms 防抖 | `app.js` `utils.debounce` |
| 节流 | 滚动加载 200ms 节流 + `requestAnimationFrame` | `app.js` `utils.throttle` |
| 事件委托 | 列表点击统一委托，避免逐项绑定 | `app.js` 各 `_onClick` |
| 离线缩略图 | SVG data URI 生成，无网络请求 | `app.js` `utils.thumbDataUri` |
| 硬件加速 | `transform`/`will-change` 触发 GPU 合成 | `main.css` |

### 4.4 响应式与主题

- **移动优先**：`viewport` 适配、`100dvh` 动态视口、`env(safe-area-inset-bottom)` 安全区。
- **断点**：`min-width:480px` 大屏切换两列栅格；横屏优化高度。
- **主题**：CSS 变量 + `[data-theme]` 切换深浅色，`prefers-color-scheme` 跟随系统，`localStorage` 持久化（不可用时内存回退）。
- **无障碍**：`prefers-reduced-motion` 减少动效。

## 五、运行方式

### 方式一：直接打开（推荐）
用浏览器直接打开 `app/index.html` 即可运行，无需任何服务端。

### 方式二：本地静态服务器
```bash
cd app
python3 -m http.server 8765
# 浏览器访问 http://localhost:8765/index.html
```

### 运行测试
- **应用内**：点击右下角"测试"浮动按钮，或"我的 → 运行功能测试"。
- **独立页**：浏览器打开 `app/test.html`，页面加载后自动运行全部 34 项测试并展示结果。

## 六、测试覆盖（测试工程师）

## 九、已知限制与后续规划

- 数据为内置 mock，后续可对接真实热点 API（`DataAPI` 已按接口契约封装，替换实现即可）。
- AI 摘要与名人观点为模拟数据，非真实模型生成。
- 虚拟列表采用"估算高度 + 实测缓存"策略，极长列表下可进一步引入 prefix-sum 缓存优化。
- 推荐算法为标签命中加分 + 热度基础分，可升级为向量召回 + 排序模型。
