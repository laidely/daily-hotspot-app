# AI热点效率站（移动端 H5 应用）

> 解决「每日 AI 热点信息过载 + 工具选择困难」痛点的单页移动端 H5 应用。
> 聚焦 2026.08 AI 办公智能体赛道（腾讯 / 字节 / 阿里 / 百度 / 360）。

---

## 一、项目简介

「AI热点效率站」是一款纯前端、零构建、开箱即用的移动端单页应用（SPA），围绕 **AI 办公热点信息过载** 与 **工具选择困难** 两大痛点，提供五大功能模块：

| 模块 | 解决的痛点 |
| --- | --- |
| 首页热点流 | 每日 AI 热点信息过载，难以高效获取 |
| 痛点分析（大佬圆桌） | 痛点洞察零散，缺乏多视角对照 |
| 效率工具推荐 | 工具选择困难，缺乏场景化推荐 |
| AI 助手对话 | 选型/趋势疑问无即时解答 |
| 个人中心 | 收藏/历史/主题，沉淀个人知识库 |

## 三、快速开始

### 方式一：直接打开
双击 `index.html`，在浏览器中即可运行（推荐 Chrome 移动端模拟器）。

### 方式二：本地服务器（推荐，图片懒加载更稳定）
```bash
# 进入 app 目录
cd app

# 任选一种方式启动静态服务
python3 -m http.server 8080
# 或
npx serve .
```
浏览器访问 `http://localhost:8080`。

### 移动端调试
- Chrome DevTools → 设备工具栏（Ctrl+Shift+M）→ 选择 iPhone / Android 机型
- 建议开启「触摸事件」模拟，体验下拉刷新与上拉加载

## 四、功能清单与实现说明

### 1. 首页热点流
- **数据**：12 条 AI 办公热点（覆盖腾讯 WorkBuddy、字节飞书/豆包、阿里千问办公、百度 Agent 矩阵、360 纳米 Work、GPT-6、Cursor 等）
- **卡片信息**：封面图、标题、来源、摘要、热度值（>7000 标红 🔥）、标签、时间
- **下拉刷新**：触摸下拉超过阈值触发，重置列表（`touchstart/move/end` + 节流）
- **上拉加载**：`IntersectionObserver` 监听底部触底，分页每页 6 条，到底显示「已经到底啦」
- **图片懒加载**：`IntersectionObserver` + `data-src`，离线自动降级为渐变兜底
- **搜索**：顶部搜索按钮，关键词匹配并高亮排序
- **点击详情**：底部弹层展示完整内容，支持收藏并写入阅读历史

### 2. 痛点分析（大佬圆桌）
- 4 位大佬视角卡片：**马斯克 / 雷军 / 张一鸣 / 王兴**
- 每张卡片含：头像（主题色）、身份、核心观点（引述）、展开洞察、标签
- 点击卡片查看完整视角弹层，可收藏

### 3. 效率工具推荐
- 7 款工具（腾讯 WorkBuddy / 豆包办公 / 千问办公 / 360 纳米 Work / Cursor / 通义灵码 / Notion AI）
- 卡片含：图标、名称、厂商、评分（星级）、价格、适用场景标签、亮点徽章
- **分类筛选**：横滑筛选条（全部 / 协作办公 / 智能体平台 / 中小企业 / 研发提效 / 知识管理）
- **一键收藏**：收藏状态实时同步，与个人中心联动
- 点击「查看详情」打开工具详情弹层

### 4. AI 助手对话框
- **本地问答引擎**：基于关键词命中的规则匹配（10 条规则）+ 通用兜底回复
- **打字效果**：逐字逐段输出，模拟真实 AI 交互
- **快捷问题**：根据回复动态推荐追问，点击即问
- 覆盖话题：产品对比、市场趋势、选型建议、痛点解读、编程工具等
- 非真实 API，纯本地数据驱动

### 5. 个人中心
- 用户卡片 + 数据统计（收藏数 / 阅读历史数 / 今日热点数）
- **主题切换**：深色 / 浅色模式开关，`localStorage` 持久化，全站即时生效
- **收藏夹**：展示已收藏的热点 / 视角 / 工具，支持删除与点击查看
- **阅读历史**：自动记录浏览过的详情，最多保留 50 条，支持删除
- 收藏/历史项点击可跳回对应详情

## 五、技术实现要点

| 要求 | 实现方式 |
| --- | --- |
| 单页架构 | 绝对定位视图 + `view--hidden` 切换，JS 路由控制 |
| 移动适配 | `viewport-fit=cover`、`rem`（375 基准）+ `vw`、`100dvh` 动态视口 |
| 安全区适配 | `env(safe-area-inset-*)` 顶部/底部留白 |
| 响应式 | 移动优先，`>640px` 自动切双列网格（平板/桌面） |
| 性能优化 | 图片懒加载、IntersectionObserver 分页/触底、防抖节流、`transform` 硬件加速动画 |
| 主题切换 | CSS 变量 + `data-theme` 属性，无刷新切换 |
| 数据驱动 | `data.js` 集中管理 Mock 数据，挂载 `window.APP_DATA` |
| 模块化 | IIFE 封装，按职责拆分 State / Storage / Router / Views / Utils |
| 持久化 | `localStorage` 存储收藏、历史、主题、上次 Tab |
| 语义化 | `<header>/<main>/<section>/<nav>/<article>` 等标签 |
| 无障碍 | `aria-*` 属性、`role`、`prefers-reduced-motion`、`:focus-visible` |
| 工程化 | ES6+ 语法、JSDoc 风格注释、防注入 `escapeHtml` |

- Chrome 90+ / Edge 90+ / Safari 14+（推荐）
- 移动端：iOS Safari 14+、Android Chrome 90+

### 6.2 核心功能测试用例

| 编号 | 测试项 | 操作步骤 | 预期结果 |

| T04 | 图片懒加载 | 滚动热点流 | 图片进入视口前不加载，进入后渐显 |
| T05 | 下拉刷新 | 在首页顶部向下拉动 | 出现「下拉刷新/松开刷新」，松开后重置列表 |

### 6.3 边界与异常
- 离线打开：图片加载失败自动隐藏，露出渐变兜底，不影响布局
- 空收藏/历史：显示空状态提示
- 重复收藏：去重处理，再次点击为取消
- 历史上限：自动截断为最近 50 条
- 不支持 IntersectionObserver 的浏览器：懒加载与分页降级为滚动监听兜底

### 6.4 性能观察
- 滚动/触摸事件均经节流（throttle 16~200ms）
- 卡片入场动画使用 `transform/opacity`，触发独立合成层
- 切换 Tab 时视图懒初始化，减少首屏负担
